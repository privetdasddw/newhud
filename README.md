# hud — HUD вокруг круга fh4map

GTA V / FiveM HUD: все блоки компактно облепляют круглую миникарту
`fh4map-1.4` — время над кругом, микрофон и погода справа, кластер
справа снизу, адрес под кругом.

- **Всё в долях радиуса круга.** Ни одной привязки к краю экрана и ни
  одного жёсткого px: высота капсулы `.31r`, кегль `.128r`, круглый
  чип `.25r`, скорость `.30r`. Круг переехал или сменил размер
  (`Config.Radar`) — вся композиция уехала вместе с ним, пропорции те же
  на 1080p / 1440p и 16:9 / 21:9.
- **Поверхности** — тёмные полупрозрачные капсулы с волосяной кромкой
  и мягкой тенью. Без backdrop-filter: CEF не размывает игровой кадр.
- **Монохром** + два функциональных цвета: янтарь (`Config.Accent`) на
  низкое топливо и активные R/S, зелёный (`Config.MicColor`) на
  говорящий микрофон и эфир радио.
- **Radar не тронут** — это отдельный ресурс `fh4map-1.4`, HUD только
  читает его геометрию (`--radar-cx/cy/r`).

## Композиция

Координаты — доли радиуса `r` от центра круга `(cx, cy)`:

| Блок | Привязка | Содержание |
|---|---|---|
| Время | центр по `cx`, низ `cy + 1.20r` | `7:26 AM` |
| Радиоканал | центр `cx - 1.31r`, `cy + 1.01r` | номер канала; в эфире зеленеет, без канала чипа нет |
| Микрофон | левый край `cx + .75r`, центр `cy + 1.00r` | глиф + три круговые линии |
| Погода | левый край `cx + .75r`, центр `cy + 0.39r` | иконка + температура |
| Кластер | левый край `cx + 1.38r`, низ `cy - 0.78r` | скорость + MPH, PRNDS, топливо |
| Адрес | центр по `cx`, центр `cy - 0.91r` | «индекс, улица» + круглый чип направления |

Кластер виден только за рулём (скрывается через `opacity`, слой
промоучен заранее — CEF не теряет альфу при посадке в машину).
Время, радио, ремень, круиз и знак лимита сверх этого списка не
рисуются (поля NUI приходят и игнорируются).

## Микрофон

Три состояния приходят полем `mic` (`off | idle | talking`) из
pma-voice / Mumble:

- `off` — глиф гаснет и перечёркивается, линий нет;
- `idle` — тихие серые линии;
- `talking` — глиф и три круговые линии зеленеют и бегут одна за
  другой, капсула получает мягкое зелёное свечение.

Анимация назначается только в состоянии `talking`: в простое CEF
ничего не крутит. Цвет — `Config.MicColor` (по умолчанию `#34d17a`),
уходит в UI сообщением `config`. Состояние опрашивается отдельным
циклом `Config.VoiceInterval` (100 мс), поэтому линии загораются сразу
при нажатии клавиши разговора.

## Установка

1. Папка `hud` кладётся в `resources/`.
2. **Отключи старый HUD `location`** (иначе будут два интерфейса):
   убери/закомментируй `ensure location` в server.cfg.
3. Добавь: `ensure hud`. Радар — отдельный ресурс `fh4map-1.4`.

## Данные и интеграции

NUI-контракт и Lua-слой прежние: те же поля
(`visible, drive, time, night, weather, temperature, street, postal,
direction, speed, unit, gear, fuel, delta, limit, cruise, seatbelt,
mic, radioChannel, radioTalking`), те же экспорты
(`setSpeedLimit / setTemperature / toggleHUD`), команда `/hud`.
Поля, которым нет блока в композиции, принимаются и игнорируются.

Интеграции (все опциональные): pma-voice (микрофон/радио), gears
(активная буква S), postal-база, температура событием.

## Производительность

- Основной цикл 400 мс (250 мс в машине), голосовой — 100 мс;
  diff-кэш: в CEF уходит только изменившееся.
- Без blur и постоянных анимаций: кольца микрофона крутятся только
  во время разговора, остальное — переходы 150–350 мс по событию.

## Превью в браузере

Открой `html/index.html` в Chrome — dev-режим с макетной сценой и
кругом radar на месте fh4map:

- `index.html` — пешком, ночь, микрофон циклом talking → idle → off;
- `index.html?veh` — за рулём;
- `index.html?veh&low` — низкий уровень топлива;
- `index.html?bright` — дневная сцена, проверка читаемости;
- `index.html?long` — самая длинная улица + 5-значный индекс;
- `index.html?mic=talking` — зафиксировать состояние микрофона.

В FiveM этот код не загружается.

## Релизы

Версия ресурса — поле `version` в `fxmanifest.lua`. Каждый готовый срез
публикуется как **GitHub Release** `vX.Y.Z` с архивом
`release/hud-X.Y.Z.zip` (папка `hud` целиком).

### Как выпустить

1. Поднять semver в `fxmanifest.lua` (`MAJOR.MINOR.PATCH`).
2. Дописать блок в этот раздел: что вошло, breaking changes, как ставить.
3. Закоммитить на рабочей ветке и запушить.
4. Собрать `release/hud-X.Y.Z.zip` из папки ресурса.
5. Создать GitHub Release `vX.Y.Z` и приложить zip как asset.

### v4.1.0 — Композиция по референсу (2026-09-06)

Вся расстановка и все размеры переделаны по присланному референсу:
блоки компактно облепляют круг радара.

**Что вошло**

- Время — капсула над кругом; радиоканал — маленький чип слева сверху;
  микрофон — капсула справа сверху; погода — справа; кластер — справа
  снизу; адрес «индекс, улица» + чип направления — под кругом
- Все размеры переведены в доли радиуса круга (`.31r` капсула,
  `.128r` текст, `.25r` чип, `.30r` скорость): HUD всегда соразмерен
  миникарте, привязок к краям экрана больше нет
- Микрофон переделан: глиф + три круговые линии, которые зеленеют и
  бегут одна за другой во время разговора
- Компас по умолчанию латиницей (`N / E / S / W`), как на радаре игры
- Адрес одной строкой: `7285, Los Santos Freeway`

**Совместимость**

Поля NUI, экспорты и команда `/hud` не менялись. Новых настроек нет
(кроме появившейся в 4.0.0 `Config.MicColor`).

Архив релиза: `hud-4.1.0.zip` (GitHub Release `v4.1.0`).

### v4.0.0 — Reference around radar (2026-09-06)

Композиция эталонного HUD, перестроенная вокруг круга `fh4map-1.4`,
плюс новый блок микрофона.

**Что вошло**

- Блоки эталона 1-в-1 (адрес, погода, кластер) в rem-пересчёте
  эталонных размеров; расстановка: адрес над кругом radar, погода —
  правый край, кластер — правый нижний угол
- Новый блок микрофона справа от круга: зелёные круговые волны во
  время разговора, приглушённый перечёркнутый чип при выключенном
  микрофоне; цвет — `Config.MicColor`
- Отдельный голосовой цикл `Config.VoiceInterval` (100 мс) — волны
  включаются мгновенно
- Ресурс снова разложен по папкам (`client/`, `html/css`, `html/js`,
  `html/fonts`) ровно так, как их ждёт `fxmanifest.lua`

**Breaking changes**

- Блоки времени, радио, ремня, круиза и знака лимита больше не
  рисуются (поля NUI сохранены и принимаются)
- Новая настройка `Config.MicColor`

**Совместимость**

Те же поля NUI, экспорты `setSpeedLimit` / `setTemperature` /
`toggleHUD`, команда `/hud`, база индексов.

Архив релиза: `hud-4.0.0.zip` (GitHub Release `v4.0.0`).

### v3.0.0 — Deck (2026-09-05)

Дизайн-оверхаул: новый визуальный язык «deck», presentation layer
переписан; radar (`fh4map-1.4`) и Lua/NUI-контракт не менялись.

**Визуальный язык**

- Стек маленьких модулей вместо крупных карточек: единый шаг,
  компактные радиусы, капсула статус-бара в основании колонки
- Ровные полупрозрачные скримы с волосяной тёмной кромкой и мягкой тенью
- Inter, герой-цифры 760, гашёные ведущие нули, uppercase-микролейблы
- Монохром + единственный акцент (`Config.Accent`, янтарь) только на
  состояния; активные P/N/D — белые, R/S — акцентные

**Композиция**

- Адрес — одна строка: postal-чип + улица + направление в конце;
  длинная улица режется многоточием, direction всегда на месте
- Скорость — герой-модуль: цифры + unit под ними, за волосяным
  разделителем знак лимита с инверсией и delta + строка селектора PRNDS
- Топливо — отдельный тонкий стрип; aux — ремень + радио;
  статус-бар время · погода · микрофон тянется на ширину колонки

**Совместимость**

Те же поля NUI, экспорты `setSpeedLimit` / `setTemperature` / `toggleHUD`,
команда `/hud`. Опциональные интеграции: pma-voice, gears, postal-база.

Архив релиза: `hud-3.0.0.zip` (GitHub Release `v3.0.0`).
