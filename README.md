# hud — Deck HUD

GTA V / FiveM HUD третьего поколения: визуальный язык «deck» — стек
маленьких модулей вокруг круглого radar. Принципы языка:

- **Поверхности — ровные полупрозрачные скримы** с волосяной тёмной
  кромкой и очень мягкой тёмной тенью: физическая кромка на ярком
  кадре без стекла и glow. Слои разделяются плотностью заливки и
  воздухом, а не обводкой.
- **Формы:** компактный радиус (модули), капсула (статус-бар —
  основание колонки), скруглённый квадрат (знак лимита), мини-чип
  (postal), круг (направление, микрофон).
- **Типографика — голос системы:** герой-цифры 760 с отрицательным
  трекингом и гашёными ведущими нулями; микро-лейблы ВЕРХНИМ
  регистром с широким трекингом (MPH, RDO, postal); улица —
  uppercase с трекингом; табличные цифры повсюду (Inter).
- **Монохром + единственный акцент** (`Config.Accent`, янтарь):
  превышение, мало топлива, разговор, эфир, непристёгнутый ремень,
  R/S-передача. Активные P/N/D — белые: цвет означает состояние.

Radar не тронут — ресурс `fh4map-1.4`, HUD только читает его геометрию
(`--radar-cx/cy/r`) и строится вокруг.

## Композиция

| Узел | Якорь | Содержание |
|---|---|---|
| Адрес (одна строка) | над кругом, левый край по левой кромке круга | postal-чип + улица uppercase + направление в конце (круглый tint-чип) |
| Правая колонка | 1rem от правой кромки, низ на нижней касательной круга | drive-стек (за рулём) + статус-бар в основании |
| Статус-бар | — | время · погода · микрофон: время первично, погода тише, микрофон прижат вправо круглым чипом |

Пешом drive-стек скрыт через `opacity` (место держится) — справа
остаётся статус-бар на опорной линии, сверху адрес. Композиция не
разваливается ни в одном режиме.

## Drive-стек

Три отдельных модуля вместо одной карточки — скорость, топливо и
вторичные лампы читаются единой системой с общим шагом.

- **Скорость** — герой-модуль 3rem/760, гашёные ведущие нули (`.dz`):
  «041» читается как 41, ширина стабильна; на стоянке — чистый «0».
- **Единица** — НЕ рядом, а ПОД цифрами: трекинговый лейбл `.3em`.
- **Знак лимита** — скруглённый квадрат-колодец со сдержанной светлой
  кромкой; превышение — акцентная инверсия, delta «+N» слева от знака
  (колонка прижата вправо — модуль не дышит).
- **Передачи** — строка селектора PRNDS: неактивные гаснут, активная —
  белая 800; R и S в активе — акцентные (состояния, а не декор).
- **Топливо** — отдельный тонкий стрип: иконка + шкала + процент;
  низкий уровень — акцент целиком.
- **Aux** — тихий стрип: лампа ремня слева (нет данных — скрыта, место
  держится; не пристёгнут — акцент), радио справа капсом (`CH-N`,
  в тишине `RDO`) с точкой-статусом.

## Масштаб

Всё в `rem` от `html { font-size: clamp(11px, 100vh/72, 34px) }` —
пропорции к диаметру radar одинаковы на 1080p / 1440p и 16:9 / 21:9.

| элемент | кегль | 1080p |
|---|---|---|
| скорость | 3rem | ≈ 45px |
| улица (uppercase) | .95rem | ≈ 14px |
| время | .9rem | ≈ 13px |
| передачи | .68rem | ≈ 10px |
| топливо % | .78rem | ≈ 12px |
| postal | .72rem | ≈ 11px |
| MPH / RDO | .62–.64rem | ≈ 9–10px |

## Установка

1. Папка `hud` уже лежит в `resources/`.
2. **Отключи старый HUD `location`** (иначе будут два интерфейса):
   убери/закомментируй `ensure location` в server.cfg.
3. Добавь: `ensure hud`.

## Данные и интеграции

NUI-контракт и Lua-слой не менялись: те же поля
(`visible, drive, time, night, weather, temperature, street, postal,
direction, speed, unit, gear, fuel, delta, limit, cruise, seatbelt,
mic, radioChannel, radioTalking`), те же экспорты
(`setSpeedLimit / setTemperature / toggleHUD`), команда `/hud`.

Интеграции (все опциональные): pma-voice (микрофон/радио), gears
(активная буква), postal-база, температура событием, лимит событием.
Круиз-контроль в интерфейсе не отображается (поле сохранено для
совместимости).

## Производительность

- Единый цикл 400 мс (250 мс в машине), voice-цикл 100 мс; diff-кэш —
  в CEF уходит только изменённое.
- Без blur и бесконечных анимаций: только переходы 150–350 мс по
  событию; тени — статичный box-shadow, композитор с ним не пересчитывается.
- Compositing guard: drive-стек скрывается через `opacity`, поверхности
  промоутятся заранее — CEF не теряет альфу в середине сессии.

## Превью в браузере

Открой `html/index.html` в Chrome — dev-режим с макетным фоном:

- `index.html` — пешком, ночь;
- `index.html?veh` — за рулём;
- `index.html?veh&over` — стресс-тест: превышение (+delta, инверсия
  знака), низкий топливо, эфир радио, пристёгнутый ремень;
- `index.html?bright` (`&veh`) — дневная сцена, проверка читаемости;
- `index.html?long` — самая длинная улица + 5-значный postal.

В FiveM этот код не загружается.

## Релизы

Версия ресурса — поле `version` в `fxmanifest.lua`. Каждый готовый срез
публикуется как **GitHub Release** `vX.Y.Z` с архивом
`release/hud-X.Y.Z.zip` (папка `hud` целиком, без `_preview_*.png` и
`_shot_*.png`).

### Как выпустить

1. Поднять semver в `fxmanifest.lua` (`MAJOR.MINOR.PATCH`):
   - **MAJOR** — ломающий контракт (NUI / Lua / экспорты) или смена
     визуального языка.
   - **MINOR** — новая возможность при обратной совместимости.
   - **PATCH** — правка, полировка, документация.
2. Дописать блок в этот раздел: что вошло, breaking changes, как ставить.
3. Закоммитить на рабочей ветке, открыть PR в `main`, влить **squash**.
4. Собрать `release/hud-X.Y.Z.zip` из папки `hud` (без `_preview_*.png`
   и `_shot_*.png`) и закоммитить архив в репозиторий.
5. Создать GitHub Release `vX.Y.Z` на получившемся коммите `main` и
   приложить zip как asset. Если `uploads.github.com` недоступен —
   workflow **Release asset** (`release: published` / `workflow_dispatch`)
   делает тот же zip и аттачит его; пока ассет не появился, качать
   `release/hud-X.Y.Z.zip` с `main`.

После каждой готовой работы — этот же процесс, не копить изменения
между тегами.
