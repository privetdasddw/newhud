# HUD по референсу: установка и разбор

## Изменения
Единственный изменённый исходный файл: `html/index.html`. В нём полные HTML, CSS и JS с комментариями. Старые CSS/JS остаются в архиве, но больше не подключаются. Lua, manifest, конфигурация, шрифты, сервер и базы индексов сохранены побайтно. Этот документ добавлен отдельно; исходный README описывает прежнюю версию.

## Установка
1. Сделайте резервную копию работающей папки `hud`.
2. Скопируйте из архива `hud/html/index.html` поверх существующего `hud/html/index.html`. Этого достаточно; не создавайте вложенную папку hud/hud.
3. В серверной консоли выполните `restart hud`. При другом имени ресурса подставьте его. Manifest менять не нужно.
4. Проверьте за рулём скорость, передачу, топливо, улицу при движении, компас, погоду, выход из автомобиля, паузу и `/hud`.
5. Для отката восстановите исходный index.html и снова перезапустите ресурс.

Для новой установки распакуйте целиком папку hud в resources и добавьте `ensure hud` в server.cfg. Не запускайте две копии HUD одновременно.

## Визуальный разбор
Приблизительные измерения по кадру 1568 x 981, не исходному дизайн-макету:

| Элемент | X, Y | Размер |
| --- | --- | --- |
| Адресная капсула | 63, 93 | 597 x 80 px |
| Погодная капсула | 1295, 355 | 206 x 74 px |
| Приборная панель | 1091, 560 | 400 x 315 px |

Шрифт визуально подобран: Arial, fallback Helvetica/sans-serif. Скорость 104 px, вес 700; индекс 28 px; дорога 27 px, вес 600; передачи 36 px, вес 600; топливо 30 px; температура 28 px. Три нуля одинаково белые. Активный режим PRNDS белый, остальные тёмно-серые, включая R/S. Дорога выводится заглавными буквами; длинные названия ограничены многоточием.

Поверхность около RGB(29,30,30), альфа .82; основной текст около RGB(246,246,247); неактивные передачи около RGB(86,86,87). Светлая обводка 1.5 px с альфа .23; радиусы около 40-42 px; мягкая тень. Современные CEF используют близкие OKLCH-значения с RGB fallback. Топливная полоса отражает реальный процент, не фиксированные 42%.

Точную прозрачность, шрифт и градиент нельзя однозначно восстановить из картинки, уже смешанной с игровым фоном. Применена равномерная полупрозрачная заливка без backdrop-filter: CEF не гарантирует размытие игрового кадра под NUI. Фон документа в игре полностью прозрачен. Элементы масштабируются равномерно через min(ширина/1568, высота/981); привязки к краям процентные. При другом соотношении сторон сохраняются пропорции панелей, а не абсолютные координаты исходного кадра.

## Сохранённая игровая логика
### Скорость
`GetEntitySpeed(vehicle)` возвращает м/с. Существующий Lua умножает на 2.236936 для MPH или 3.6 для KMH по `Config.Unit`, затем округляет. Сейчас конфигурация MPH. NUI получает готовые speed/unit и повторно их не пересчитывает.

### Передачи
Если `gears` запущен, используется защищённый pcall вызов `exports.gears:GetGearLabel()`. Первая буква приводится к верхнему регистру и принимается как P/R/N/D/S, другое непустое значение становится D.
Без gears исходный fallback сначала проверяет `GetVehicleCurrentGear(vehicle) == 0` и возвращает R. Затем при скорости ниже 0.5 м/с возвращает N с работающим двигателем либо P с выключенным; иначе D. S без интеграции не появляется. Если на остановке native возвращает 0, HUD покажет R: это поведение исходного Lua, сохранённое намеренно. UI не выдумывает P по нулевой скорости.

### Топливо
Приоритет: числовое `Entity(vehicle).state.fuel`, затем декоратор `_FUEL_LEVEL` через `DecorGetFloat`, иначе `GetVehicleFuelLevel`. Lua округляет и ограничивает 0..100. NUI дополнительно защищает диапазон; неизвестное значение показывает как --%, а не как нулевой бак.

### Адрес и компас
Координаты получаются через `GetEntityCoords` от машины или персонажа. Дорога: `GetStreetNameAtCoord` -> `GetStreetNameFromHashKey`. Функция исходника сокращает английские суффиксы Boulevard, Freeway, Highway и другие. Отдельный район через GetNameOfZone исходный HUD не получает.
Индекс выбирается по ближайшей точке XY. Основной источник `HUD_POSTALS` из client/postals.lua, fallback: собственный new-postals.json, файл ресурса location, затем серверный запрос hud:requestPostals и ответ hud:setPostals. Дорога и индекс пересчитываются после перемещения больше Config.MovementRadius, сейчас 3 м.
Компас берётся из GetEntityHeading и четырёх секторов Config.Compass: С, В, Ю, З. Поэтому 7285 действительно почтовый индекс, а С означает север. В игре это динамические значения, не заглушки из референса.
Язык улиц зависит от игры. Manifest уже содержит client_language 'ru', но если native возвращает английскую строку, NUI не переводит её искусственно: CSS меняет только регистр.

### Погода и температура
GetWeatherTypeTransition и хеши погоды определяют sun/cloud/fog/rain/thunder/snow. Встроенные SVG поддерживают все ключи, иконка не фиксируется на облаке.
Температура поступает через location:updateTemp, hud:setTemperature или exports.hud:setTemperature(celsius). Формат задаёт Config.TempUnit, сейчас F. При старте используется KVP cluster_hud_last_temp; если значения нет, через 20 секунд Lua один раз оценивает его по погоде. До получения данных выводится --°, не выдуманные 70°F.
ВАЖНО: fallback исходника не пересчитывает температуру непрерывно. Для постоянно меняющейся температуры нужен существующий внешний источник события/экспорта. Погодная иконка обновляется независимо. Это ограничение сохранено, игровая логика не изменялась.

### NUI, видимость и остальные данные
Сохранён контракт action=hud с частичными изменениями, action=config, action=reset и POST https://<имя ресурса>/uiReady. Данные diff сначала объединяются со старым состоянием, затем рисуются; отсутствующие поля не обнуляются. При reset старые значения очищаются, HUD скрывается и повторяет handshake. При отказе запроса старта выполняются ограниченные повторные попытки.
Основной цикл Lua отправляет изменения каждые 250 мс при вождении, 400 мс иначе. Config.VoiceInterval объявлен, но отдельного цикла на нём в данном main.lua нет.
Адрес и погода зависят от visible, приборная панель от drive. Config.Passenger=false сохранён: пассажир спидометр не увидит. Команда /hud, экспорт toggleHUD, скрытие в паузе/катсценах/при скрытом радаре, debounce видимости и скрытие стандартных GTA-подписей работают по прежнему Lua.
Время, микрофон, радио, ремень, круиз и ограничение скорости не рисуются: их нет на картинке. Источники, поля состояния и интеграции не удалены. Config.Accent и Config.Radar не меняют оформление нового эталона: он монохромный и не привязан к миникарте. LowFuel принимается для совместимости, но не перекрашивает полосу.

## Предпросмотр и проверки
Откройте html/index.html в обычном браузере: только вне FiveM включатся серый фон и демонстрационные 7285 / 000 MPH / P / 42% / 70°F. Добавьте ?demo для анимации данных или ?walk для состояния пешком. В игре демоданные не запускаются.
Синтаксис JS и логика проверены в Node с имитацией DOM/NUI: частичные обновления, PRNDS, границы топлива, неизвестные значения, текст без HTML-инъекций, скрытие, config/reset и handshake. Результат в TEST_RESULTS.txt.
Настоящий браузерный рендер и FiveM не проверены: браузерный движок в среде не установлен, доступа к вашему серверу нет. Точное визуальное совпадение нужно проверить в игре, особенно на ярком фоне и другом разрешении.
